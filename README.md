# Home Decor Ecommerce

Tienda online de artículos de decoración para el hogar.

## Puesta en marcha

> [!IMPORTANT]
> Inicia el frontend con este comando:
>
> ```bash
> ng serve --host 127.0.0.1
> ```
>
> Y accede siempre desde el navegador a **http://127.0.0.1:8090**.
